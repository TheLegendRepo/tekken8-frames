# T8 Frames (Tekken 8 frame data, Expo + TypeScript)

Offline-first: all data is bundled from `src/data/framedata.json` (schema in `src/data/types.ts`).

## Run
    npm install --legacy-peer-deps
    npx expo start      # scan QR with Expo Go (iOS/Android), or press i / a for simulators

## Data
The bundled JSON is an **illustrative sample** (3 characters, placeholder values, NOT verified).
Real source candidate: wavu.wiki, whose text content is CC0 (game content remains owned by Bandai Namco).
To use real data, generate a file matching `types.ts` and replace `framedata.json`; set `meta.isSample` to false.

## Features
Character list + search; per-character moves with notation search, sorting (startup/block/hit/CH/damage),
filters (launchers, i10-i15 punishers, safe, homing, power crush).

## UI
Dark theme with amber accents, a character grid, and per-character tabs: Frame Data, Cheat Sheet (computed from the data) and Flash Card.
Frame Data has search, Sort by, Filter, View Mode (Default/Compact/Detailed), tap-to-sort column headers, favorite hearts and expandable rows.
Favorites and flash card progress are saved on the device (AsyncStorage). Flash cards: Flip, Wrong, Correct, Ignore.

## Clips, Guide, Anti Strats
Move clips come from wavu.wiki, or from tekkendocs.com for moves wavu has no clip for (Bob, Anna, Armor King, Kunimitsu, Miary Zo, Roger Jr. and others), and are streamed, not bundled. The ▶ button opens the move's page (`src/app/move/[id].tsx`), which plays the clip muted and looping with 0.25x/0.5x/1x speed buttons (`expo-video`). On flash cards, ▶ plays the clip in place so the answer stays hidden. Each move has an optional `clipUrl` and `clipSource`; when a move has no clip of its own, it uses the clip of the shortest longer string that starts with it and `clipFrom` names that string. To use a different clip, tap Edit on a character, expand a move, and type a URL (saved on device). Coverage per character and the moves with no clip are in `scripts/clip_coverage.md`.
`character.guide` / `character.antiStrats` are lists of `{title, body}` sections; each tab also has device-local "My notes".

## Real data (current)
`src/data/framedata.json` is generated by `scripts/import_tekkendocs.py` from the TekkenDocs wavu-derived CSVs (43 characters, 6,680 moves).
See `scripts/coverage_report.md` for per-character coverage and flagged values. Regenerate:
    python3 -I scripts/import_tekkendocs.py <tekkendocs>/data/wavuConvertedCsv <tekkendocs>/app/constants/characterInfoListT8.ts src/data/framedata.json scripts/coverage_report.md
Values are stored as source strings (e.g. "i15~16", "+13a"); sorting/filtering parse the first number.
Then attach clips (re-run after the import above, which drops them):

    python3 -I scripts/import_clips.py

It reads wavu's Cargo `Move` table (`video` field) and `list=allimages` for direct MP4 URLs, then fills gaps from the clip names on tekkendocs.com character pages (their CDN URL suffix is read from each character's move page). It rewrites `scripts/clip_coverage.md`. okizeme.gg and rbnorway.org were checked too and have no clips beyond wavu's.

`scripts/fetch_wavu.sh` (untested; needs network access to wavu.wiki) dumps wavu's Cargo Move table directly.
